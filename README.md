# ⭐ 星棋 (StarChess)

**一个现代化、精美且趣味十足的网页端国际象棋对战与智能AI辅助小程序**

*仿多邻国 (Duolingo) 风格的扁平化鲜明 UI 交互，支持单机人机对战、Firebase 实时联机对决、多模型 AI 实时互动解说与对局复盘教练。*

## 📖 项目简介

**星棋** 是一款基于纯 Web 技术栈构建的创新国际象棋应用。项目打破了传统国际象棋软件严肃、沉闷的界面风格，引入了极其生动鲜明的配色、卡片化圆角控件、SVG 自绘卡通棋子以及极致顺滑的动画交互。

除了基础的本地对弈与联机功能外，项目深度接入了 **Stockfish** 引擎用于局面推演与难度分级，更创新性地将大语言模型（**DeepSeek** / **OpenAI** / **Kimi**）无缝融合进棋局中。你可以自定义 AI 的“人设”、“称呼”和“生成字数限制”，在下棋时与 AI 进行实时对话与战术探讨，享受前所未有的沉浸式对局体验。

## ✨ 核心功能特性

### 1. 🤖 智能引擎对局 (Lv.1 - Lv.20)

* 内置 **Stockfish 10 国际象棋引擎**（基于 Web Worker 异步计算，完全不阻塞 UI）。
* 支持 20 级难度动态调节。当你将死 AI 时自动晋升难度，战败则降低难度，极具挑战性。
* 玩家可自由选择执白、执黑或随机分配。

### 2. 🌐 零后端 Firebase 实时联机对决

* 利用 **Firebase Realtime Database** 实现无服务器架构的 P2P 房主-客态联机对战。
* **一键邀请**：房主创建房间后可直接复制专属对战链接发送给好友。
* **极速同步与消息去重**：棋盘走法与联机状态秒级同步，采用唯一 MessageID 机制彻底解决多端消息重复问题。
* **内置聊天室**：联机对局支持发送预设嘲讽短语，以及高度自适应的自定义文字发言框，长文本自动拉伸且不遮挡棋盘。

### 3. 🔥 多模型 AI 实时互动与复盘教练

* **AI 局内实时对话**：AI 对战中，玩家可随时点击“发言”按钮，利用自适应高度的多行文本框与 AI 进行自由对话。AI 会敏锐感知当前局势、你的落子表现以及 Stockfish 的评分波动，以你设定的“独特人设”回应你。
* **极致自定义参数**：支持完全自定义 AI 对话风格（如“阴阳怪气”、“高傲、目中无人”）、对玩家的称呼，以及**最大生成字数限制**（留空则不限字数，可长篇大论分析棋局）。
* **人格化复盘教练**：对局结束后进入复盘模式，随时呼出 AI 教练获取基于当前 FEN 串的战术指导。**复盘教练同样会严格遵守你的个性化人设和字数设定。**

### 4. 📱 极致细节的沉浸式 UI/UX

* **全端完美适配**：采用现代的 `100dvh` 与 `min(100vw, 50vh)` 动态响应式视口约束，确保不论手机屏幕多小，棋盘与底部控制台绝不溢出或被遮挡，并支持屏幕旋转自动重绘。
* **多邻国式主题与高对比点**：提供 7 种高颜值主题配色（暗夜黑、樱花粉、琉璃蓝、经典绿、柠檬黄、烈焰红、星云紫），配合高对比度的灰色落子提示点，视觉体验极佳。
* **点击式悬浮操作**：摒弃易误触的传统拖拽，采用“点击悬浮并放大 -> 预览落子点/吃子红圈 -> 移动”的交互，极致适配触屏操作。
* **震撼碎裂特效 (Shatter Animation)**：将军时王棋会剧烈颤抖发红；当你成功将死对手（无论是 AI 还是真人）时，对方的王会触发极具视觉冲击力的**爆裂、碎化消失特效**。
* **聊天瀑布流**：所有的系统通知、走子评价和玩家发言均采用瀑布流追加模式（Append），历史记录可随时向上翻阅。

### 5. 🔄 局后复盘与悔棋机制

* 支持单机模式下的**无限悔棋**功能。
* 本地自动缓存历史棋局每一步的 FEN 数据，支持在主页点击“**复盘上局**”通过前后导航按钮逐帧回顾整盘棋局。

## 🛠 技术栈

项目为纯前端静态单页应用（SPA），架构轻量且无需搭建复杂的后端服务器：

* **核心架构**：原生 HTML5、CSS3、JavaScript (ES6+)
* **UI 与 棋盘**：
  * [Chessboard.js](https://chessboardjs.com/)（UI 渲染定制与坐标管理，经过深度无拖拽改造）
* **规则与推演**：
  * [Chess.js](https://github.com/jhlywa/chess.js)（规则校验、走法合法性生成、胜负判定）
  * [Stockfish.js](https://github.com/nmrugg/stockfish.js) (基于 Web Worker 的引擎)
* **联机后端**：[Firebase Realtime Database](https://firebase.google.com/) (v8)
* **大模型支持**：DeepSeek API / OpenAI API / Moonshot (Kimi) API

## 🚀 快速开始

由于本项目是纯前端应用，你不需要安装任何 Node.js 环境即可直接运行。

### 方法一：本地直接运行

1. 克隆或下载本项目到本地：
   ```bash
   git clone https://github.com/XUNJIANMAX/StarChess.git
   ```
2. 直接双击打开 `index.html`，或者使用任意静态服务器（如 VS Code 的 **Live Server** 插件）打开即可体验。

### 方法二：一键部署上线

你可以将项目托管至任意静态网页托管服务（如 **GitHub Pages**、**Vercel**、**Netlify** 或 **Cloudflare Pages**）：
1. 将所有文件上传至你的代码仓库。
2. 在托管平台开启静态部署，根目录直接指向 `index.html` 即可发布全球。

## ⚙️ 配置说明

### Firebase 配置 (联机功能)
项目内置了测试用的 Firebase 配置项。若需搭建自己的独立数据库，可在 `app.js` 顶部修改 `firebaseConfig` 对象。

### AI 密钥配置 (大语言模型)
在应用内点击 **设置 -> AI 对话风格设置** 即可配置你的 API 密钥、选择模型供应商并定义字数与人设风格。
> 🔒 **隐私声明**：所有配置项（包括 API Key、人设设定、历史对局等）均仅保存在你浏览器的本地缓存（`localStorage`）中，绝不上传任何第三方服务器，请放心使用。
